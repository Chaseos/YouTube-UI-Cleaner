# YouTube terminology matrix

Audited 2026-09-09. This is the pre-fix research snapshot, not a replacement dictionary. “Current” aliases/matches refer to audit time; see [implementation status](implementation.md). See [audit report](README.md) for risks, source limitations, and corrections. Full current alias lists and matcher details are in [terminology-matrix.json](terminology-matrix.json).

**D** = documented control/tag; **T** = documented product term, not exact UI; **L** = live English UI; **F** = regional fallback, not verified for Hong Kong; **U** = unverified. **†** means the evidence string is not matched by the current code (or differs from an injected label). A † on T/F is a validation candidate, not proof of a live filtering failure.
